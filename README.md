# فهرس الجوال
تطبيق Android 11 فأحدث. فهرسة محلية للتخزين المشترك، بلا إنترنت أو حساب أو مزامنة.

## التثبيت
حمّل Mobile-Index.apk من Releases بعد اكتمال Build Android APK. اسم التطبيق وأيقونته مضمّنان في المشروع. اسم المستودع لا يؤثر على اسم التطبيق.

## الاستخدام
1. اضغط السماح بالوصول ثم فعّل الوصول لجميع الملفات في إعدادات النظام.
2. ارجع واضغط تحديث الفهرس.
3. ادمج فلاتر النوع والمجلد ووضوح الاسم والتاريخ والحجم والترتيب مع البحث بالاسم أو المسار.
4. اضغط النتيجة لفتح الملف أو موقعه في مدير ملفات يدعم فتح المجلدات.
5. بعد نقل أو حذف الملفات بنفسك من مدير الملفات اضغط تحديث الفهرس.

التطبيق يقرأ بيانات الملفات الوصفية فقط ولا يفحص محتواها. لا يحتوي كود نقل أو حذف أو كتابة ملفات المستخدم. موفر الملفات يرفض أوضاع الكتابة والتحديث والحذف. صلاحية النظام الواسعة تتيح وصولًا عامًا تقنيًا، لكن التطبيق يستخدم القراءة فقط. ملفات التطبيقات المحمية والملفات المخفية مستبعدة. الفهرس داخل مساحة التطبيق الخاصة ويُزال عند إزالة التطبيق. فتح مجلد يعتمد على دعم مدير ملفات الهاتف، مع عرض المسار وخيار نسخه عند عدم الدعم. الأسماء التي تحتاج مراجعة تقدير بقواعد بسيطة وليست تصنيفًا لمحتوى الملف.

## البناء
JDK 17، Gradle 8.9، Android SDK 35: `gradle assembleDebug lintDebug`.
GitHub Actions يبني APK وينشره في Release v1.0.0. يستخدم مفتاح debug ثابتًا محفوظًا في إصدار signing-key للتحديثات المحلية؛ ليس مفتاح إنتاج أو نشر متجر. لا تضع بيانات خاصة في المستودع.
